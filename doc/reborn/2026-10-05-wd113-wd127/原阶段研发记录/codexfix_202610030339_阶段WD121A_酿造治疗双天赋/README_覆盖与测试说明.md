# WD121A 酿造治疗双天赋累计测试包

状态：已完成源码/数据接入与离线检查，待用户编译、游戏实测。基于WD120A累计文件；保留WD119B面板修复、WD119C蛙变冷却/移动中断。WD119C、WD120A未收到明确实测通过反馈，不能因本包交付而视为验收。

## 本批测试两项

|天赋|加点条件|本批效果|
|---|---|---|
|新鲜配料 / Fresh Ingredients，2级|酿造方案，先投入8点基础酿造TE，每级1 TE|大锅丛林蘑菇的范围周期治疗提高15%／30%；二级替代一级，不叠成45%。|
|药水增效 / Potion Boss，1级|酿造方案，先投入8点基础酿造TE，1 TE|药水投掷直接治疗及其附带的丛林蘑菇持续治疗提高20%。|

两项可以同时保存，分别作用于大锅脉冲和投掷治疗，不会把同一项蘑菇治疗重复放大。不会增强洛阿佳酿、沃金守望或其他无关技能，也不改变持续时间、冷却或耗蓝。本批只适配目前开放的蘑菇配料；其他配料、泼洒药水仍未开放。

8点基础酿造TE来自既有五项基础节点（7131、30884、29736、5055、7129），同层后续天赋不能互相凑前置。这两个被动可以先学习，但要测试其效果，必须拥有并准备WD120的丛林蘑菇；投掷测试还需药水投掷。

节点、技能书和原生拖动图标采用相同节点资源。主动技能的绿色“当前治疗”提示继续读取服务端，包含本批加成；它是计入自身加成的参考范围，不包含目标增减益、暴击和过量治疗。既有友方持续治疗保留施加时数值，改点/换方案后重新投掷再测。

## 逐项实测

1. 先确认WD120基础链：保存酿造方案、准备蘑菇；范围治疗每6秒，药水投掷15秒冷却及18秒持续治疗。确认WD119C蛙变实际60秒冷却和读条移动中断（先等旧冷却结束）。
2. 固定等级、装备、增益和目标，目标保持受伤。未点新鲜配料先记蘑菇脉冲数值；一级应约乘1.15，二级约乘1.30。取多次非暴击有效样本，允许整数舍入及本来随机范围；不是用满血时的有效治疗比值。
3. 点药水增效后重新投掷：直接治疗和随后每次HoT各约提高20%；蘑菇大锅脉冲不再因它提高。只点新鲜配料时，投掷及其HoT不应提高。
4. 检查主动技能绿色当前治疗提示随保存后的被动更新。快速移动鼠标、查看未激活方案、撤销草稿，都不应把草稿数值当成实际值。
5. 旧方案和已购买第二套方案保持。切走酿造应撤销这两个被动；切回/重登恢复最高已保存等级。已保存的点不能免费撤回，正常付费重置后增益消失。
6. 酿造技能书中出现新鲜配料和药水增效，图标与节点一致；新鲜配料二级不会同时保持一级光环。回归假死药剂拖动、技能书翻页和DBM无新增弹窗。

# WD121B 蛙变术冷却施法后同步（专项覆盖包）

修复对象：贡克祝福生效时，蛙变术提示60秒，但动作条仍从2分钟开始。

源码发现：WD119C在 SendSpellGo 之前发送准确冷却；既有施法成功后的纠正分支只处理迅捷召唤，遗漏贡克祝福。本包补齐该分支，读取服务器已经保存的剩余毫秒数，发送清除客户端旧倒计时及准确冷却。不会再次减60秒，也不清除服务器冷却记录。该时序是与现象吻合的源码证据，尚无实机抓包确认。

## 覆盖

1. 基于已覆盖的WD121A累计源码，保留现有客户端Lua、双端DBC及数据库。此包是专项增量，不是新的全量累计包。
2. 备份你的源文件，将 `01_覆盖到源代码根目录` 内文件按路径覆盖源代码根目录。共两个文件：Spell.cpp新增修正，Player.cpp保留WD121A/WD119C的原生冷却计算与早期同步。
3. 重新编译worldserver，使用新编译服务端并重启。仅覆盖源码或reload客户端不会生效。
4. 本次无需导入SQL、替换DBC或更新Lua。前提是原累计包的数据已经安装。

## 游戏验证

- 等原有冷却完全结束，保存并激活带贡克祝福的方案，再成功施放蛙变术：动作条应约1分钟，约60秒后可再次使用。
- 无该祝福、或改选克拉格瓦祝福时，成功施放后应为基础2分钟。120秒等于2分钟，不是120分钟。
- 移动打断读条：不应成功施放，也不应产生完整技能冷却。
- 迅捷召唤影响的旧技能仍按其实际服务器冷却计时。
- 如果仍显示2分钟，请同时记录约61秒时能否再次施放，以及本次是否已替换新编译worldserver；可据此区分服务器计时与客户端预测。

# WD126A 缩小盟友累计测试包

本包以 WD125A 为基线，包含 WD124B 的 `wanted` 重名编译修正、WD123B 及之前的累计资源。**WD125A 的鱼油／蛙骨及 WD124A 的三项被动仍待用户实机确认**，不能把本批离线检查视为实机通过。

新增酿造节点 **缩小盟友**（节点 30888，私有技能 9003910）：在已保存并激活的酿造方案投入 8 点基础 TE 后花 1 TE 学习。对一名存活友方施放，持续 8 秒，闪避几率提高 50%，模型外观缩小约 25%；2 分钟冷却，消耗 15% 基础法力。它是可拖到动作条的主动技能。移植沿用官方 Spell 806282 的三个效果槽、光环数值、持续时间和冷却；本项目将技能等级设为 10，并采用现有友方 40 码框架与标准 1.5 秒公共冷却。这两项属于 WotLK 适配，待实机检查。

## 覆盖顺序

1. 备份当前源码、Characters／World 库、客户端 Patch-XA 与双端 DBC。把 `01_覆盖到源代码根目录` 覆盖至当前 WD125A／WD124B 累计源码，自行重新编译。
2. 在 **Characters** 库执行 `server_SQL/01_CHARACTERS_WD126A_必须执行.sql`，替代 WD125A 旧 Characters 过程。已有方案不自动重置。已安装的 02／03／04／05 World SQL 不必重复执行。
3. 在 **World** 库执行 `server_SQL/06_WORLD_WD126A_必须执行.sql`，注册缩小盟友脚本。若此前 World SQL 有缺漏，先按包内编号补装。
4. 覆盖 `02_覆盖到客户端根目录`；将 `client_mpq输入_导入现有Patch-XA` 的内部路径导入当前 Patch-XA；停服覆盖 `03_覆盖到服务端根目录`。两端 Spell.dbc 分别取各自目录，不能互换。重启服务端与客户端。

## 请实机测试

1. 酿造方案先有 8 点基础 TE，再点缩小盟友，保存、激活；技能书酿造栏目出现“缩小盟友”图标，可拖动作条。未保存或切到没有该点的方案时不能施放。
2. 对存活友方施放：观察 8 秒外观与闪避变化，动作条从约 2 分钟开始冷却；法力消耗与技能书显示一致。8 秒后两个光环效果都消失。
3. 对敌方、死亡目标尝试施放应失败；切方案、重登后核对技能是否只归属已保存激活方案。回测 WD124A／WD125A 酿造技能与技能书分页。

# WD127B 四轮累计编译修正版


> **WD127B 替代 WD127A。** 修复 WD5A::AEIds 定义88项、声明86项的数组长度冲突，并把天赋读取和已保存节点防免费退点的遍历统一到同一个 AEIdCount=88。这导致的模块构建失败会连带出现 modules.lib 缺失；先修前一错误再重新编译。本轮无新SQL／DBC／Lua改动，尚未重新编译验证。已覆盖WD127A源码的用户，只需用本包 01_覆盖到源代码根目录 重新覆盖后编译；若WD127A SQL／客户端／双端DBC尚未安装，则按本包完整说明一次安装。

本包以 WD126A 为基线，累计包含 WD124B 的 `wanted` 重名编译修正、WD124A 药水投手／药师／再生者、WD125A 鱼油／蛙骨、WD126A 缩小盟友，以及本轮 WD127A 蛇神门徒。前面三轮仍由用户实测，本包离线通过不代表游戏内通过。只需使用 **WD127B 最终累计包**覆盖一次，不必顺序覆盖四份 ZIP。

## 本轮新增

**蛇神门徒 / Disciple of Sseratus**（官方节点 35051；私有被动 9003911）：酿造树已有 8 点基础 TE 后投入 1 TE，保存并激活。本项目现有洛阿佳酿和瓶中之灵的额外治疗系数各提高 15%（0.84→0.966，0.45→0.5175）；破咒术会额外尝试解除原目标 8 码内最近一名友方的诅咒，公共冷却最多降到 1 秒。8 码为本项目对官方“附近”的具体适配距离，需实机观察。被动不单独出现在技能书里；切换没有该节点的方案时立即移除。

官方来源：`CharacterAdvancementData.json` 节点 35051 与 `patch-T.MPQ/DBFilesClient/Spell.dbc` 技能 300660；原始记录存于 `research`。官方文本明确三项效果，原始被动的三个光环为 Bonus Multiplier、Jump Targets、Global Cooldown；本项目采用服务端脚本作用在私有技能上，避免改变其他职业同类技能。上游公开源码在项目给定的 `2099e7b9eb7a624347374069aed13b33df8b2924` 快照中未找到这组新技能的完整实现，按官方客户端数据移植。

## 覆盖和测试

1. 备份当前源码、Characters／World 库、客户端 Patch-XA 与双端 DBC。把 `01_覆盖到源代码根目录` 覆盖至当前工程，重新编译。
2. 在 **Characters** 库执行 `server_SQL/01_CHARACTERS_WD127A_必须执行.sql`，它替代旧 Characters 过程，原有方案不自动重置。World 端保持 WD126A 包中 02–06 SQL 已装好的状态；本轮没有新增 World SQL。
3. 覆盖 `02_覆盖到客户端根目录`；将 `client_mpq输入_导入现有Patch-XA` 内部路径导入当前 Patch-XA；停服覆盖 `03_覆盖到服务端根目录`。双端 Spell.dbc 不能互换。重启服务端和客户端。
4. 先按 WD124A／WD125A／WD126A 的各轮说明回测，然后在酿造树点蛇神门徒，保存激活。比较洛阿佳酿、瓶中之灵的治疗值；对两名靠近的友方施加诅咒后施放破咒术，验证两人均解除并观察约 1 秒公共冷却；切换不含节点的方案重复施放，第二目标不再受益。

`rollback_WD126A` 保存本轮改动前的文件。已有新节点方案保存后，旧 SQL 会拒绝未知节点；如需完整回退，请使用升级前数据库备份。

离线验证：双端 DBC 的 WD126A 所有旧行和字符串前缀不变，新被动不占技能书槽；隔离 MySQL **469 项**检查通过，包括新节点存取、方案切换限制、未满足前置、错误专精与旧方案回归。**尚未替用户编译、部署或实机测试。**

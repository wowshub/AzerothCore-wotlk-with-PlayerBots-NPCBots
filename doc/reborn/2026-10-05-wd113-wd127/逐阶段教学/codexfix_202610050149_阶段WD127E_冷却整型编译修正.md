# 本轮类型修正教学

C++ std::min与std::max默认要求两个参数是同一类型。0的类型是int，RecoveryTime是uint32；uint32减5000的结果仍为无符号类型，所以不能自动匹配。目标核心SpellInfo.h第378行可查到uint32 RecoveryTime。

修正：
```cpp
rec = std::min<int32>(rec, std::max<int32>(0, int32(spellInfo->RecoveryTime) - 5000));
cooldown=std::min<int32>(cooldown,std::max<int32>(0,int32(info->RecoveryTime)-5000));
```
int32(...)先将毫秒数转为有符号数，再做减法。std::max<int32>把结果限制到至少0；std::min<int32>在当前冷却与目标冷却中选较小值。如果原生修饰已变为10000，结果仍10000，不会重复减到5000。两处分别用于实际冷却和数值提示，计算方式必须相同。

checks/after.cpp使用constexpr和static_assert让MSVC在语法检查时验证结果，无需生成可执行文件。旧before.cpp故意保存原报错表达式，MSVC /Zs失败是预期结果，不是待交付错误源码。完整工程需要用户重新编译验证。

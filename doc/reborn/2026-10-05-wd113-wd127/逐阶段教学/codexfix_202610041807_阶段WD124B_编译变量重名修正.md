# 为什么一个变量名会阻断整包编译

C++ 不允许在同一个函数作用域同时定义 `wanted[4]` 和 `wanted[8]`。数组长度不同也不能让它们成为两个独立变量。把第一组改为 `supportWanted`，并仅修改它自己的使用位置，就能保留后来八项数组的原行为。编译器先拒绝生成 modules 库，链接器随后自然找不到 `modules.lib`；排错时应先修最早的 C++ 错误，而不是手动复制一个旧库进去。

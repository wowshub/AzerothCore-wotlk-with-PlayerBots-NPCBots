# SpellDraft 界面稳定与性能：别把一张书画一百遍

## 类比

界面像舞台：`parent` 决定演员属于哪个剧组，`frame level/strata` 决定谁站前面，刷新函数决定什么时候换布景。把装备槽设成最高层，就像演员跑到所有舞台前；每次开书重新造演员，就会卡顿并留下“黑方块尸体”。

## 正确分层

- 主书负责显示/隐藏与拖动。
- 技能页、天赋页、神秘附魔页只是主书内部页面。
- 装备槽、平均装等、Hide 按钮必须 parent 到人物预览页。
- 拖动时移动真实书框，不用黑色全屏遮罩冒充预览。

## 性能思路

```lua
if snapshotSerial == lastRenderedSerial then return end
```

这叫“幂等刷新”：同一份权威数据只渲染一次。卡片先建好，之后改文字、图标并把多余卡片 `Hide()`；不要每次 `CreateFrame`。

## 重复点击保护

开关动作要有单一入口和短防抖：第二次按键只改变显示状态，不能同时发第二组快照请求。完整分片到齐后再替换旧表，缺片则保留旧画面。

## 测试

边走边跳连续开关 20 次；拖动书；切换两个页签；同时打开人物、法术书、任务、成就、幻化；重登后再测。观察帧率、Lua 错误和书框下方是否出现幽灵卡片。

来源：B0.9.17.4～17.7、20.3～20.4.2、21.4～21.4.2、22.0。右动作条 2 仍须回归确认。

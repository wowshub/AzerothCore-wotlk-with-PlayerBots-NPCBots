## 安装（基于已安装WD142A及其前置版本）

1. 关闭游戏和服务器，备份程序、Data、world/characters数据库及客户端原PATCH-XA+PATCH-ZA。MPQ备份放Data目录之外。
2. 从本Release标签取得源码编译。源码不放进运行目录，本资源包不含EXE/DLL。
3. 手动向characters库依次执行03_导入SQL/characters_角色数据库的01_node_reference.sql、02_save_rows.sql；向world库执行world_世界数据库/01_WD143_world.sql。已执行过相同WD143脚本无需重复；不要递归导入历史SQL。Auth无更新。
4. 将04目录内容覆盖服务端根目录，并部署对应编译程序。双端DBC不可互换。先完成SQL再启动新布局。
5. 把01目录内187个文件按内部路径导入**现有完整PATCH-XA.mpq**，保留原来的其他文件。此目录不是完整XA，不能把小包改名替换整个XA。
6. 完成XA导入后，再把02目录覆盖客户端根目录。其patch-ZA.mpq仅为配套清理文件（25840字节），保留原6个LIGHT8资源；不能单独先换ZA。若ZA后来新增过其他功能，必须先合并，不能直接覆盖。
7. 启动后刷新服务器状态，在暗影方案选择三项免费节点并保存。需要远程武器与弹药。

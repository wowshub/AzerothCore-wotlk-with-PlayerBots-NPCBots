# DCCHAT1 聊天记录复制面板 验收记录

- 日期：2026-10-17；开发：Claude；验收：用户。
- 用户原话："这个聊天记录 复制功能 通过 可以推送了 明天再测试其他几个方面吧"。
- 范围：只有客户端插件 DungeonClear 的聊天记录面板（`/dc chat`，坐标窗口的【聊天记录】按钮）。服务端没有改动。
- 发布版本：插件仓库 wowshub/mod-dungeon-clear-addon `v3.6-reborn22`（提交 e65630016f2c96d90bd208bc96e6c062f9a404d8），Release 附件 SHA256 8381fbe81c7c7000bce3af2b8683d0c0e8e10ff8bd47cad3ab124c506c1f3f77，已读回。
- 发布包里聊天记录面板的代码与用户实测的版本逐字相同（29690 字节）。

## 功能
并排两个视图【只看我的命令】【全部聊天】；命令亮青色、输出白色缩进、其他行可选色；面板自带输入框；斜杠命令和点命令都记录；复制全部/复制上一条命令输出/选中模式；屏蔽词；`/reload` 后保留。

## 版本经过（均为候选，现场逐版实测）
| 版本 | 结果 |
|---|---|
| 1A | 刷屏、输入框占住键盘 |
| 1B | 按钮打不开（建立中途出错） |
| 1C | 能打开但建了一半：这个客户端的输入框没有 OnArrowPressed 脚本 |
| 1D | 面板完整，但把别的工具自动发的命令当成用户的 |
| 1E | 与聊天框一致、屏蔽词；仍不记录斜杠命令、颜色与命令分不开 |
| 1F | 斜杠命令、颜色区分、并排按钮；仍混进机器人说话（名字无方括号） |
| 1G | 按频道名认出说话，等待窗口缩短。**用户确认通过** |

## 没有包含的内容
测试用插件里还带着首领清单（DCTEST7A）、作弊档（DCGM1B）、跑尸（DCRZ2B）的客户端部分，**未测试，未发布**，已从发布版本中剔除。

## 未单独验证
- 没有 AwesomeWotlk 扩展时的手动 Ctrl+C 路径。
- 多个聊天窗口：只记录主聊天框（ChatFrame1）显示的行。

## 经验
- 这个客户端的输入框不支持 `OnArrowPressed` 脚本。新界面按"放在保护里建立 + 阶段标记 + 出错红字"的方式写，可选的接口单独保护。
- 判断"是不是用户输入的命令"，不能把"光标在某个输入框里"算进去，否则别的插件自动发的命令会混进来。
- 判断"是不是说话"要按频道标签，不能假定名字带方括号。

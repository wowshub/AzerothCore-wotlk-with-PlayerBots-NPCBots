# WD142A：三个巫医通用技能候选测试包

状态：离线检查通过，等待用户游戏测试。不是已验收Release。本包在已通过WD139C、WD140A、WD141A的环境上使用。

## 这次真正移植的三个技能

| 天赋 | 类型与作用 | 加点要求 |
|---|---|---|
| 黑暗帷幕 / Veil of Darkness（30203） | 主动：敌人受到本人伤害提高15%，持续15秒；40码且视线可达时每1.5秒一次暗影伤害；90秒冷却，8%基础法力 | 56级、先花24点既有通用AE，再花1 AE；普通点数最早58级 |
| 洛阿共鸣 / Loa Communion（6052） | 被动：黑暗帷幕的周期伤害提高100%，不把15%易伤翻倍 | 58级、黑暗帷幕、24既有通用AE，再花1 AE；普通点数最早60级 |
| 邦桑迪的虔诚 / Devotion to Bwonsamdi（29757） | 被动：本人直接伤害的10%治疗自己；持续伤害、宠物和复制伤害不触发 | 56级、24既有通用AE，再花1 AE；普通点数最早58级 |

三个都在左侧通用天赋树，三种专精均可使用。普通无额外点数时三个一起最早62级。你80级可以测试，但仍需先投入24通用AE；TE不能替代AE。
使用现有已解锁方案即可，不要求买第三方案。为对照洛阿共鸣，可用两份已有方案，一份点黑暗帷幕，一份再点洛阿共鸣；不要为了对照频繁付费重置。

## 安装顺序（请先退出游戏、停服，备份）

1. 备份角色数据库和World库，以及本包同名源码、当前程序、客户端patch-ZA与插件、服务端Data/dbc。
2. `01_覆盖到源代码根目录` 内文件覆盖到 AzerothCore-wotlk-with-PlayerBots-NPCBots 根目录，由你重新编译。没有新增.cpp，不要求为本包重新CMake；新增.inc已由原.cpp包含。包含一个共享核心头文件 WitchDoctorTalentPolicy.h，其余为巫医范围。
3. 按 `03_导入SQL/导入哪个数据库.md`：**角色库先执行01_node_reference.sql，再02_save_rows.sql；World库执行01_WD142_world.sql。全部成功后才能启动新程序。** 不导入auth库，也不要重新导入旧A/B包SQL。只复制SQL文件不等于导入。
4. `04_覆盖到服务端根目录` 中的Data覆盖服务端根目录；然后使用你刚编译的程序启动。此包不包含worldserver.exe。
5. 游戏完全退出后，`02_覆盖到客户端根目录` 的Data和Interface覆盖你当前客户端根目录。客户端路径为 newrebornWOWli20261011beAscend；覆盖现有patch-ZA.mpq，不删除其他MPQ。进入游戏测试。

本批正式节点增加3个：256容量不变，111槽/110有效节点，旧108槽不动；通信123位、31个十六进制字符。新程序、新插件、新SQL和双端DBC必须配套。旧入口保留，但只允许表达旧节点；新版校验会拒绝用旧入口删除已保存的新节点。

## 大白话测试顺序

1. 先看原来的酿造方案、提基泼洒、魔精鱼骨和购买方案还在。不要一上来重置所有方案。旧方案保存、/reload、小退重登各试一次。
2. 左侧通用树凑满24点，点黑暗帷幕并保存、激活。法术书应出现主动技能；拖到动作条。不是只点亮浏览卡片就算激活。
3. 对能活15秒的敌人施放黑暗帷幕：看15秒减益、周期伤害、90秒CD和法力消耗；跑出40码或隔墙，跳伤应暂停，回来继续。单次伤害基础随等级成长，另加10%暗影法强和4.5%攻击强度，再经过实际抗性/增益结算。
4. 用相同装备、相同目标比较有/无洛阿共鸣；排除暴击和其他临时BUFF，帷幕周期伤害应约翻倍。普通技能不会一起翻倍；15%本人易伤维持15%。
5. 点邦桑迪的虔诚保存激活，自己先缺血，用普通攻击或直接伤害技能打怪，观察自己受到治疗。不是给队友治疗，也不是满血时储存盾。治疗量会受减疗、治疗吸收、过量治疗影响；只放持续伤害或让宠物打，不应单独触发。
6. 切到没有这些天赋的已保存方案：主动应撤销，被动不再触发，旧目标上本人的帷幕应清除。再切回来、/reload、小退重登，节点及动作条检查一次。
7. 如方便，两名玩家攻击同一怪：帷幕的15%只给施放者本人，不能给另一个玩家共享。顺手试死亡、跨图及副本目标；这些现场行为仍需实测。

推荐反馈：学到/放出、帷幕跳伤、共鸣对比、虔诚回血、切方案撤销、重登保存，分别说是否正常。若异常附目标、方案、技能名和战斗日志，不必重新测试整个职业。

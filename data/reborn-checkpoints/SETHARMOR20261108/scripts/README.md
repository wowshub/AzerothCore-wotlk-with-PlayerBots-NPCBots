# 脚本说明（SETHARMOR1A/1B，蛇人男女 v8）

这些脚本是做蛇人装备叠加层时用的原样脚本，**路径是写死的**（D:\_zsdc、D:\000rebornWOW…），不是一键工具。复用时先改路径，再按下面顺序跑。

## 男性（v8）

| 脚本 | 作用 |
|---|---|
| `seth_m2.py` | 读 StormLib 的小工具（rd），以及 M2 贴图/分区的解析示例 |
| `seth_build8.py` | 构建：给 M2 追加类型 1 贴图槽、查找项、替换表；改身体顶点 UV2（左右镜像映射）；每个 skin 重排三角形、追加只含身体的分区和叠加批次；写透明占位 BLP |
| `seth_bake8.py` | 烘焙：把颜色图集按 UV1→UV2 光栅化成 512x512，抖动量化，写 6 张 skin11_tN.blp |
| `seth_bake_faces8.py` | 把烘焙底图的裁片写成 24 张脸/内衣贴图（FL/FU/LU/TU） |
| `seth_verify8.py` | 离线校验 |

## 女性

`seth_female.py build|bake|faces|verify` 一个脚本四个阶段。和男性的区别：只改身体顶点的 UV2（特效层在用 UV2）、复用已有的 UV2 查找项、批次数组不在文件末尾、身体分区按顶点是否属于身体判断、skin 原件在 YB。

## 辅助

- `dr_extract.py`、`dr_analyze.py`、`dr_torso.py`：从客户端提取原版德莱尼/人类模型，分析标准身体 UV 排布（用来确认"左右镜像共用，躯干正面在最左、背面在最右"）。
- `mk_v8.py`：把 v7 的映射改成镜像对称的补丁脚本（留作历史）。

## 重要约定

- 每次构建都从 `orig_true`（第一次导入前保存的真原件）读取，不要从客户端当前的 MPQ 读。
- 构建输出目录、烘焙预览 png、校验报告都保留在包的 `checks` 下。

# 教学：新种族为什么穿不上胸甲、腿甲，怎么让它穿上

配套 Skill：[overlay-armor-on-nonstandard-uv-race-models](../../beascendskills/overlay-armor-on-nonstandard-uv-race-models/SKILL.md)。

## 一句话

头盔、肩膀、武器是"挂"在角色身上的独立小模型，所以新种族也能显示；胸甲、腿甲、手套、靴子是"画"在角色皮肤上的图，新种族的皮肤图是自己做的，装备图没有地方画。我们的办法是：在皮肤外面再贴一层"装备贴纸"，贴纸只管装备，蛇皮本身不碰。

## 打个比方

把角色想成一个人偶，皮肤是人偶身上的一张包装纸。

- 原版人偶的包装纸有固定的格子：左上是手臂、右上是躯干、下面是腿。装备图就按格子贴上去。
- 蛇人的包装纸是自己设计的，每个部位随便摆。装备图按原版格子贴，就贴到了错的地方（脸上被贴了衣服）。

我们做的事：不动蛇人原来的包装纸，另外给身体加一层透明膜，膜上的格子按原版排。装备图贴在膜上，膜盖在身体上。

## 为什么这么麻烦

1. **客户端合成出来的图没有透明度**。"没装备的地方"不是透明，而是不透明的黑色。所以不能指望"膜是透明的、有装备才不透明"。
2. 解决办法：让膜的底图不是"空"，而是蛇皮本身（把蛇皮按原版格子重新排一遍"烘焙"进去）。装备画上去，盖住的是蛇皮；没装备的地方，看到的还是蛇皮。
3. 原版的包装纸是**左右镜像共用**的：身体左边和右边用同一块图。所以我们的排法也必须左右对称，这样装备的花纹才端正。我们第一次做成"绕身体转一圈"，花纹就歪了，像衣服穿歪了。

## 新人最容易犯的错

| 错误 | 后果 |
|---|---|
| 觉得"把底图做成透明"就行 | 没装备的地方变黑或变绿 |
| 底图换格式（比如 DXT）不和原文件一致 | 客户端不认，变绿 |
| 把头也烘焙进去 | 头只分到很小的格子，眼睛丢了 |
| 把身上的装饰件（金饰、绑带）一起烘焙 | 装饰颜色盖掉蛇皮，像裹了一层布 |
| 从客户端当前的文件重建 | 你读到的是上一版改过的文件，越改越乱 |
| 绕身体一整圈取图 | 左右不对称，花纹歪 |

## 你怎么自己检查有没有做对

1. 用用户的截图和客户端里读到的实际文件对照，不要凭记忆。
2. 离线核对：原来的三角形有没有被改变、头部有没有被排除、新加的批次指向对不对。
3. 先看创建页的"NO装备"（没穿装备时身体）和"T7 装备"（穿装备），再看游戏里。

## 做不到的

靴子、披风、长袍需要新的几何体，这个方法不能凭空画出来。想要没穿装备时和原版完全一样，只能接受装备"发光叠加"的效果（相加混合）。

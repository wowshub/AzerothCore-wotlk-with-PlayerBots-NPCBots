## 一、蛇人为什么只能戴头盔和肩膀，穿不上胸甲、腿甲

### 先打个比方：人偶和包装纸

想象每个角色是一个**塑料人偶**。人偶身上包着一张**包装纸**，这就是"皮肤"。

- 暴雪原版的人偶，包装纸是**固定格子**的：左上角那一块永远是手臂，右上角那一块永远是躯干，下面是腿，脸有自己的格子。胸甲、腿甲、手套这些装备，本质上是**一张张小贴纸，贴在对应的格子里**。
- 头盔、肩膀、武器、盾牌不一样：它们是**另外做的小模型，挂在人偶身上的挂钩上**，跟包装纸没关系。

所以蛇人只能显示头盔和肩膀：那些是挂钩上的东西。胸甲这种"贴纸"，要看包装纸的格子对不对。

### 蛇人的问题在哪

蛇人的包装纸是**自己设计的，没按原版格子排**，每个部位随便摆。装备贴纸按原版格子往上贴，要么没处贴，要么贴到错的地方（比如把衣服图贴到脸上）。Codex 之前遇到的"衣服盖脸"就是这样，他当时把这条路关掉了，所以胸甲就没了。

### 我们怎么解决的

**一句话：不动蛇人原来的包装纸，在身体外面再罩一层"装备膜"，这层膜按原版格子排。**

1. 给模型多加一层膜，膜只罩在身体上（胸、手臂、手、腿、尾巴），**头不罩**，所以眼睛脸都是原样。
2. 膜上的格子，按原版的排法排。
3. 装备贴纸贴在膜上，膜盖在身体上，所以你看到的是装备盖住了蛇皮。

### 为什么这么麻烦：一个关键事实

**这个游戏客户端把"没贴贴纸的地方"画成不透明的黑色，不是透明。** 所以不能指望"膜是透明的，贴了贴纸才不透明"。我们前后试了八个版本才摸清楚：

| 版本 | 试了什么 | 结果 |
|---|---|---|
| v1 | 透明的膜 | 没装备的地方变**亮绿色** |
| v2 | 换对格式的透明膜 | 绿色没了，但没装备的地方是**黑的**，脱下装备全身变黑 |
| v3 | 改成"叠加发光"的方式 | 蛇皮透出来了，但装备**像在发光** |
| v4 | **把蛇皮"印"进膜里**，膜完全不透明 | 装备**真的盖住**蛇皮了，但头被盖成黑的 |
| v4b～v5 | 修头、修颜色 | 头罩有竖条，身体变成黄绿裹布 |
| v6 | 只印身体 | 裹布没了，但头没有眼睛了 |
| v7 | 头完全不参与 | 头好了，装备盖住身体，但花纹**歪斜**、不对称 |
| **v8** | **全部改成左右对称的排法** | **用户说好看，男女都通过** |

### 最后一个大发现：左右对称

原版人偶的包装纸是**左右镜像共用**的：身体左边和右边是**同一块图**。所以装备的花纹天然左右对称。我之前是"绕着身体转一整圈"取图，左右各占一半，等于把本该镜像的花纹拉歪了——所以你说"像衣服穿歪了"。改成"到身体中线的距离"来取图（左右一样），花纹一下就端正了。

### 这个做法的代价（别人用的时候要知道）

- 没穿装备时，身体的蛇皮是"印进去"的，**比原版糊一点**，而且**左右镜像**。
- 靴子、披风、长袍、袖子**还是显示不出来**：模型里没有这些东西的"形状"，贴纸没地方贴，这个办法变不出形状。
- 身体上原来自带的装饰件（金饰、绑带）**在装备外面**，会挡住一部分装备。

### 用户测过什么（别夸大）
男、女蛇人在**创建页和选角界面**，T7 装备的胸甲、腿甲、护臂、手套都盖住了蛇皮，左右对称，头是原版，6 个肤色没问题。男性 v7 在游戏里也看过。**没测**：靴子等不显示的、女性进游戏的动作、所有装备组合。

## 二、库尔提拉斯男性的头盔为什么飘起来

### 比方：头上的挂钩

头盔是**挂在头上一个挂钩上**的。挂钩的位置，模型里**写了两份数据**：

1. "挂钩的位置"（`pos`）；
2. "挂钩所在的那根骨头的原点"（`pivot`）。

人类模型里这两个数是一样的。库尔男性模型里**不一样**：挂钩位置比骨头原点**多了向前 0.17、向上 0.21**。头盔就被挂得**偏前偏高**，飘到头顶外面去了。

### 怎么修的
Codex 把挂钩位置**改回和骨头原点一致**，只改了一个模型里 **12 个字节**。用户测过：头盔回到头上了。

### 这里面我犯过一个错（记下来给后来的人）
我看到"库尔变体的头盔在我扫的几个档案里找不到"，就说"缺库尔版本的头盔"，还猜"男性还在用人类前缀"。**Codex 核对后纠正**：原生库尔头盔在另一个档案（Patch-6）里本来就有，种族前缀也是男女共用的，不是缺。我的错在于：**只扫了几个档案就下"缺资源"的结论**。教训：说"没有某个文件"之前，必须把所有档案都找一遍，找不到的、没扫到的都要说清楚。

但我发现的另一件事是对的：我拿两个模型的挂钩数据对比，发现"挂钩位置和骨头原点不一致"，这个线索被 Codex 用来修好了。

## 四、怎么看懂一个 Lua 错误（顺手学的一招）

报错 `bad argument #2 to 'SetFormattedText' (string expected, got nil)`：

1. "bad argument #2"：第 2 个参数有问题；
2. "got nil"：传进去的是空的；
3. **容易被坑的地方**：对这种"冒号调用"的函数，序号**不算 self**。所以"#2"其实是物品链接，不是格式文字。我最初就是这么看错的，用户用游戏里的一条命令证明文字是有的，我才回头重新读。
4. 下一步：往上看调用栈，找谁传了这个参数，再看这个参数是怎么来的（这次是 `GetMerchantItemLink` 在客户端没缓存这件物品时返回空）。

## 五、一句话总结

- **想让新种族穿上胸甲**：别改它的皮肤，加一层按原版格子排的"装备膜"，左右对称排，头不参与，膜底要印上蛇皮。
- **头盔飘了**：看挂钩的两份数据一不一致。
- **说"缺东西"之前**：把所有档案都找一遍。

# WD137A 调酒大师（Master Mixologist）候选测试包

## 这次增加什么
- 酿造天赋29740，主动技能9003957，59级，必须先保存激活调制大师6026，再花1 TE。119位方案数据；原节点编号和位序不动。
- 瞬发、持续10秒、2分钟冷却。四种配料的大锅效果、投掷/泼洒附效提高100%；期间可以移动施放瓶中之灵9003460–67。
- 严格按官方配料掩码落到现有蘑菇、鱼油、蛙骨、血蓟。不是所有酿造技能增强：不加药水直接治疗、范围、持续时间、层数；不放大独立基底野兽之血/水晶之水、调制大师吸血、巫毒大锅。
- 原生百分比增效与已有同类百分比修正按核心规则结算，不承诺与地根草等叠加时“最终面板再乘2”。HoT、护盾等沿用原生施放快照，强化期间施加的附效不被粗暴重置；大锅区域效果在切换及准备周期刷新。

## 大白话测试
1. 59级以上酿造方案，先学调制大师，再选调酒大师并保存激活。技能书出现新主动；重新登录仍保留。未学前置或58级不能选。
2. 准备蘑菇，记录同属性、同目标的大锅治疗，再开调酒大师对照；找缺血目标，避免过量治疗掩盖差别。不同时改变装备/配料/其他天赋。
3. 分别测试鱼油、蛙骨、血蓟：开技能前/期间/结束后对比区域增益；投掷和泼洒附带HoT/盾/增益都检查。主药水直接治疗不应凭空翻倍，尤其要排除暴击干扰。
4. 普通状态移动施放瓶中之灵应失败或打断；调酒大师10秒期间应能边走边施放；Buff结束后恢复原限制。移动施放其他技能不应被一起放开。
5. 切到未学此技能的方案，主动和增益应撤销，其他人的配料不应被本人的增益修改。
6. 顺手回归灵魂链接神像名称、召唤栏及WD136吸血。新包只算候选，反馈通过后才提交发布。

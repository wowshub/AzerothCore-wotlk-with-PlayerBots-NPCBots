## 本次实际修复
1. 法力初始化：旧_OnManaUpdate遇到最大法力<=1直接返回。巫医初始零法力时因此无法计算基础法力/智力加成。现在仅对巫医允许正常重建法力池；正常空蓝仍是空蓝，不每次加满，不免费用。不据此声称已经确定是哪一刻把运行法力清零。
2. 治疗选人：60码内查找同地图/相位、存活、友好且同队的玩家/Playerbot/NPCBot。先救<=25%的危急目标，再照顾受伤坦克，再照顾普通队友；坦克85%以下开始治疗，其他人70%以下。原生坦克标记之外，正在被打的熊/巨熊也认作当前承伤坦克，兼容本次德德熊。
3. 治疗移动：目标超过28码或被遮挡时，使用原生寻路主动接近到约20码。每秒最多发一次接近命令，不把友方当攻击目标。巫医有战斗治疗任务时，通用跟随/攻击站位不再抢走治疗移动；其他职业默认保持原逻辑。待命/停止/已下达命令、禁用战斗站位、控制、载具、跳跃限制保持。
4. 急救优先：已准备配料时优先药水投掷，否则尝试阿洛药剂；仍走原生技能开关、等级、费用、GCD、冷却和施法检查。危险目标等待治疗冷却时只尝试回蓝/治疗守卫，不落入DPS轮转。保留更靠前的假死/化蛇/幻象自保与恢复。
5. 诊断：[WDN5A heal]每2秒最多一条，记录目标名/GUID、血量、坦克判断、距离、法术、检查结果、法力、职责和命令。cast-started是原生施法请求被接受，**不是有效治疗量**；实际命中/过量治疗仍以游戏战斗记录为准。

## 推荐测试（同一副本、同一队伍）
分别测试“只选治疗”和“治疗+输出+远程”，每种打一波。
- 坦克走到巫医30–50码前方并掉血：观察巫医是否跟上并治疗，而非退回主人。
- 坦克50%血、普通队友60%血：优先坦克；普通队友20%血：应先抢救危急者。
- 观察蓝条上限正常；正常耗空法力不会凭空回满。残血自保后应恢复治疗。
- 点待命/停止时不应擅自追赶；恢复跟随后再测试。重登/换地图/死亡复活后复测。
- 如果还有卡住，请保留Server.log的WDN5A段：approach表示接近，casting表示正在施法，check-rejected有原生错误码，urgent-wait表示急救技能暂不可用。
本包不新增复活技能，不改Playerbots、Cgc装备/被动、清本或Claude遥测。

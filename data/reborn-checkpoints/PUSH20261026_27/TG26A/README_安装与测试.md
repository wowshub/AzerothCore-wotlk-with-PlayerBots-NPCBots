## 安装
1. 完全退出游戏，备份现有 RebornTalentGuide、RebornClassTalentPanels 及 WTF 个人收藏。
2. 将 `02_覆盖到客户端根目录` 内的 Interface 合并覆盖到现有游戏客户端根目录。不要删除整个 Interface 或 WTF。
3. 本包累计包含前面战士、圣骑士、巫医、猎人、潜行者、牧师天赋中心内容，再加入死亡骑士；已有 TG24B/TG25A 客户端可直接覆盖，不必逐包重装。其他依赖插件保持现状，**不是纯净客户端完整安装器**。
4. **本轮无需编译、没有 SQL、无需导入 DBC/MPQ。** NPCBot 服务端继续使用你已安装的上一包，本包不更新服务器。
5. 登录死亡骑士，用飞升天赋入口打开 TG26A 三卡首页，选择鲜血/冰霜/邪恶进入独立大树。浏览不会切专精或施法；推荐与收藏仍需比较并确认后逐点学习。

# TG31B 圆形小图标与巫医双风格切换
依赖：先安装 TG31A 十二职业累计包，再覆盖本补丁。共7文件；客户端更新，不用编译，不用SQL/DBC。

## 安装与使用
退出游戏，备份同名文件，将02_覆盖到客户端根目录内Interface合并到游戏根目录。不要删除整个插件目录。TG31A新绘纹理仍保留，切勿删除。
- 巫医默认恢复安装TG31A之前的原版CoA风格，包括首页三系插画与天赋树背景。
- 首页右上“原版 / Original”或“新绘 / New art”显示当前风格，点击切换；首页立即刷新，随后进入树使用该风格。选择存入RebornWDArtStyle，正常退出/重载后保留；如客户端崩溃未写SavedVariables，不能保证最后选择落盘。
- 其他11职业：首页代表天赋由44×44缩为36×36，间隔改44，三图居中；使用旧客户端原生SetPortraitToTexture圆形裁切和巫医同款ClassPortraitRing，保留Tooltip和浏览入口。巫医原有圆形代表图标不改。
- 仅改外观。不会自动加点、换方案、洗点或付费；没有移除新绘美术。未来新职业是否复用另行设计。

## 建议副本测试（游戏均未运行）
1. 一名队友中诅咒：看破咒术是否释放、对应诅咒是否消失；无诅咒不要空放。
2. 中毒/疾病：看万灵药净化和短时免疫；多人受影响时看群体版本。
3. 单体万灵药后群体技能应共同等待90秒；群体后双方共同等待120秒。关闭其中一项不能绕过共享CD。
4. 坦克残血时先治疗；血线稳定后再净化。观察实际蓝耗，不能只看施法动作。
5. 关闭技能、停止/不行动/禁施法应生效；隔墙、异相位、未组队目标不处理。
6. 接着复测C的主人/队友战后复活，以及上一批治疗追赶、假死/化蛇/幻象和正常输出。

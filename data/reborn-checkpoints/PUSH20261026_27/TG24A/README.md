## 安装
1. 完全退出游戏，备份客户端 Interface/AddOns/RebornTalentGuide 和 RebornClassTalentPanels，以及现有 WTF 存档。
2. 把 `02_覆盖到客户端根目录` 里面的 `Interface` 合并覆盖到正在使用的客户端根目录。两插件应一起覆盖。
3. 登录猎人，点击原天赋推荐入口，或使用既有职业天赋入口。无需导入 SQL、无需更换 MPQ/DBC、无需编译或覆盖服务端。不要删除 WTF，不要覆盖个人收藏存档。

## 安装
1. 退出游戏，备份自己当前 Interface/AddOns 中本包同名文件。
2. 将 02_覆盖到客户端根目录 内的 Interface 文件夹合并覆盖到游戏根目录。不要删除原插件目录，也不要拿本包替代完整客户端。
3. 保留已安装的完整 RebornWitchDoctorTalents 插件：本包仅覆盖它的 Art.lua、HomeArt.lua 两份纹理字典，其余代码继续使用已有版本。
4. 重新进游戏，检查插件加载，再进行下面的测试。
本批为客户端更新，无 01 源码编译、03 服务端数据、SQL、DBC 或 MPQ 导入操作。无需编译，无 SQL 专用包。未包含新 NPCBot 服务端修复，已有服务端包继续使用。

## 武僧注意事项
先打开原生武僧天赋面板，等待当前方案同步，再使用大面板。只允许对当前激活且当前查看的方案加点；未同步、正在切换、查看其他方案或执行中切换方案时拒绝或停止加点。
保留原有三方案查看、切换、开通与费用确认；新增状态 API 只返回副本，不自动开通或付费。第三方案不按普通双天赋组处理。
81 个真实节点、195 个等级法术，三系各 65 点容量。四套满级参考：踏风 65/6/0、酒仙 0/65/6、织雾 0/6/65、练级踏风 65/6/0，共 71 点。它们是合法参考模板，并非最优配装保证。

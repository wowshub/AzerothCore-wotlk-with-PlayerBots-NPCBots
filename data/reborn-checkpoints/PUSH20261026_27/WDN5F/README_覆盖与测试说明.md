## 日志开关
在实际使用的RebornBotTelemetry.conf追加或修改：
```ini
RebornBotTelemetry.NpcBotRezLog = 1
```
重启后复现；看Server.log中的 `[NPCBOT-REZ]` 和 `[NPCBOT-REZ-CAST]`。默认0，不自动开启服务器现有配置，不改已有NpcBotHealLog设置。测试结束可设回0并重启。
每个机器人每5秒最多扫描并记录一次当前死亡名单，每名候选最多一条；施法结果另限每机器人5秒一条。日志不强制施法、不改蓝量、不清战斗标记。
字段含机器人/主人、目标GUID、技能/启用、蓝量/费用、距离/LOS、命令状态、读条、阻挡队友及其攻击者数量/当前目标、已有请求、即将自动复活、副本遭遇状态。reason为当前首先命中的门禁，其他布尔值帮助辨别同时存在的原因。eligible-await-native-cast仅表示预检查符合，仍需看CAST的check/started/prepare，不代表复活成功。

## 实现
- 每次现取同实例、同相位、所有权正确且在当前队伍的NPCBot；去重，不保存跨帧裸指针。死亡记录也保留供消费端判断。
- 智能休息纳入存活NPCBot血蓝，治疗职责使用NPC_BOT_ROLE_HEAL，与Playerbot职责枚举隔离；等待提示会显示NPCBot姓名。保留现有智能休息超时/解除/重新触发规则。
- 集合/就绪纳入存活NPCBot距离、血蓝；团本沿用人数比例规则，NPC坦克/治疗仍须就绪。描述原因同步加入NPCBot。
- 复活能力复用WDN5F/H已有分支，不重复造一套。巫医玩家有已学复活技能可识别；托管巫医与NPC巫医仍由其独立AI施法。NPC识别改用统一采集，即便主人死亡/灵魂在别图，队内仍在本实例的活NPC也可被识别；停用施法/停止、技能未启用、死亡或尸体不在60码内不冒充可用复活者。
- NPC仍在真实交战（有目标或攻击者）时，不消耗等待复活的脱战时间。未取消实例禁复活、全队脱战或恢复超时限制。

## 测试方法
1. 开启清本与智能休息，在副本中让已入队NPC治疗低于当前治疗蓝量阈值，或NPC低于血量阈值。观察等待及状态栏是否出现它的名字；恢复后是否放行。满血满蓝对照一次。
2. 普通集合/就绪：队内NPC超出允许距离，应显示距离原因；靠近后解除。第2步跟坦克尚未做，本轮不会主动把NPC拉到坦克身边，主人带它靠近即可测试。
3. 坦克死亡、NPC巫医存活且复活技能可用、离尸体60码内：应等待其独立复活，而非立即以“无复活者”关闭。全队脱战及副本允许复活仍是条件；若失败保留NPCBOT-REZ/CAST和清本日志。
4. NPC死亡、退组、换地图/相位、禁用复活技能时，不应把它计为活复活者。死亡NPC自身如何复活仍沿用原系统，本包未接入Player专用复活施法动作，也不新增死NPC单独等待流程。
5. 不开清本、真人手动/托管切换、停止清本，对照NPC专属随从行为无变化。只含Player的队伍回归一次。
不要为了制造失败禁用现有安全规则；有实例禁复活或真正超时时，本包并不保证清本永不关闭。

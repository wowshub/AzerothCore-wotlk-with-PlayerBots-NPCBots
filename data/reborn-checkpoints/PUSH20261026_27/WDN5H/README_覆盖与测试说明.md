# WDN5H NPC巫医法力妖术与辅助恢复累计测试包

基于WDN5G累计35个源码/配置模板文件。本批仅改bot_witch_doctor_ai.cpp和RebornWitchDoctorNpcDebuff2.h，其余33文件与G逐字节一致。保留前面的战斗、治疗、复活、净化、巫祝、默认关闭日志与清本联动；不是整职业最终验收包。

## 安装
只将01_覆盖到源代码根目录里的内容覆盖到：
D:\000rebornWOW\000RebornWOWHighForkPRO\beascendcode\AzerothCore-wotlk-with-PlayerBots-NPCBots

**没有新增SQL、客户端或Data/DBC，不需要重复生成NPC。** 前置为已有巫医累计数据与WD26A技能绑定；本包不是新服安装器，不重新执行旧WD26A SQL（后续已有WD151等附加绑定）。
先按checks/manifest.json逐文件核对历史/日常/输出哈希，遇到不匹配先合并。**先覆盖再编译，中间不插其它编译**，按项目“编译前运行_更新已修改文件时间.bat”更新文件时间并处理旧obj，再编译game/modules并部署重启。新增头被AI与RebornWitchDoctor.cpp共同引用，两者都要重编；累计公共头/清本改动也需重编引用单元。运行初始化标记为[WDN5H] initialized entry=900260。

助手未修改日常源码与运行目录，未编译交付EXE，未部署、执行生产SQL、推送或Release。

## 本批变化
- 26级获得法力妖术9003210；“伤害类技能”独立启用/关闭；隐藏吸蓝子技能9003211不进菜单。
- 仍有法力且以法力为当前资源的目标优先法力妖术；无此需求时，移动目标优先迟缓，其余优先缩小。
- 优先技能未学、关闭、冷却或施法被拒绝，可尝试缩小/迟缓备用；失败后5秒退避，继续其它战斗机会。
- 原恶意妖术维护顺序保留。同一目标任意施法者已有Jinx均不覆盖，因此本包不会立刻替换你或队友已经上的缩小/迟缓。
- 原生8秒持续、2秒一跳、30秒冷却、8%基础法力；实际吸取返还、等级成长和法力上限由原生引擎结算，没有免费施法或手工加蓝。
- 迟缓是移速减益，取消“看见读条就优先迟缓”的旧选择依据。没有借用主人天赋。
- 希里克妖术会恐惧并加速野兽，本批未加入自动输出，避免副本恐惧引怪。

## 建议测试顺序（以下游戏均未运行）
1. 输出+远程，启用法力妖术，打一只有蓝条且尚未带Jinx的法系怪：先观察恶意妖术，再看法力妖术图标、约8秒持续、敌人掉蓝及机器人回蓝。过量回蓝会被满蓝上限截断。
2. 同条件改打一只无蓝近战怪：应使用缩小；移动目标可优先迟缓，不应空放法力妖术。
3. 关闭法力妖术：应继续输出和其它减益。已有任何人的Jinx时不覆盖；等其结束再观察。
4. 冷却中、空蓝怪、LOS阻挡、停止行动和可破控目标，检查不反复卡住或误放；读条、GCD和耗蓝仍走原生逻辑。
5. 顺带复测治疗、战后复活（含释放灵魂）、净化、脱战巫祝与清本关闭。相关源码累计保留，不因本批测试替代这些项目的游戏验收。

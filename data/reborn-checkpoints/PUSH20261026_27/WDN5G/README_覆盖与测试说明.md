## 自动策略
使用法力的目标默认节能；非使用法力目标默认力量；对应单体和强效版都禁用/未学时，才考虑灵魂。想测试灵魂：在“其它/支援技能”同时关闭不想使用的普通版和强效版。每项仍有独立开关。
每目标只维持一种巫祝。其他施法者留下的巫祝保留到消失；自己不同种类的巫祝也不自动顶掉。自己的同类巫祝缺失或剩余≤60秒才补，永久效果不反复刷新。升级/改开关不会立即洗掉旧增益，需等待消失或主动取消后观察。
至少两名范围内目标需要同类增益时考虑强效版，否则单体补。NPC群体目标按需求筛选：物理和法力职业可各得适合的一种，不能给不需要的队友覆盖原巫祝。目标仍需活着、友方、同图同实例同相位、真正队友、视线可达；路人/敌人/普通宠物排除。
单体AI仅在30码内补，不为加增益追远处目标；群体仍沿用原100/30/40码。施法时目标列表再次检查，期间新获得外来巫祝的队友会被排除。
仅战后补，附近同队有人仍在战斗就先不补；已有读条、坐骑、载具、脱险、停止/不行动/禁施法均阻止补增益。紧急治疗和复活优先，治疗缺蓝储备状态先保蓝，施放后至少保留约1/3最大法力。每2秒最多一次规划；真正施法走正常CheckBotCast/doCast，失败不手动扣蓝/重置CD。

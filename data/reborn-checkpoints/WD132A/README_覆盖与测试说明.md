## 本批内容

本批是一个完整被动及两个附效，不是三个独立技能。

|节点/法术|用途|实现|
|---|---|---|
|4733 / 9003937 魔精波动|40级酿造免费被动|已选择洛阿祝福后选择并保存；0 AE、0 TE。仍须拥有魔精光束才能发挥作用|
|9003938 扩散治疗|光束有效治疗后触发|复制本次有效治疗的50%，治疗原受治疗者20码内最多2名最低生命百分比的团队友方，排除原目标与满血目标|
|9003939 恢复|成功施放魔精光束时给予|40码内最多10名法力友方，每5秒回复5%最大法力，持续15秒|

扩散对象也须在施法者40码内并满足视线；同生命比例按GUID稳定排序。复制治疗不再次计算施法者加成或暴击，目标治疗承受和吸收按原生流程处理；不递归长分支、不额外减少药水冷却，也不派发额外治疗触发链。原光束的有效治疗仍保持此前分支/冷却逻辑。
回蓝优先最低当前法力比例，范围内团队/自己及符合团队关系的单位。不是每个光束跳数重复刷新。施放成功后即使移动中断光束，已给予的15秒恢复继续；没有法力缺口时日志与实际可恢复量应区分。
9003939与普通原生恢复57669互斥，以后施加者替换前者；多施法者不应相加。特殊GM法术61782不纳入这个普通恢复互斥组。

## 实机验收步骤

1. 40级以上酿造方案选洛阿祝福、魔精波动并保存，关窗再开、切换方案、重登，确认9003937拥有权。它免费，不扣AE/TE；39级或缺前置不能选择。旧技能仍能保存。
2. 学会魔精光束，组至少3名友方，令他们都缺血并在20码内，对其中一人引导。战斗日志应同时出现光束治疗和9003938扩散；每次原光束有效治疗最多向另外两人扩散。光束本身会长分支，判读时区分9003932原治疗与9003938复制治疗。
3. 无额外治疗承受加成/吸收时，原治疗实际加血1000，复制基础应为500（向下取整）；存在目标承受加成时最终数值可变化。原治疗全过量时不扩散；移到20码外、40码外或隔墙的目标不应得到复制。
4. 让队友缺蓝后成功施放光束，查看9003939：15秒内每5秒一次回复。最大法力10000且缺口充足时每跳500。记录战斗日志，扣除自然回蓝；光束施法者自身同时耗蓝，不能只凭蓝条净变化判断。
5. 施放光束后立刻移动中断：已给予的恢复继续至15秒到期。第二位巫医施放应刷新/替换，不能使单跳回蓝翻倍；与57669分别按两种先后次序检查仅保留一个普通恢复。
6. 保存带魔精波动但未点“泼洒他们”的方案，扩散仍应出现。点了泼洒他们时，原治疗减冷却保留，复制治疗不能额外再减。原WD131两魔精、森金两次加速、配料与旧冷却只做受影响回归。

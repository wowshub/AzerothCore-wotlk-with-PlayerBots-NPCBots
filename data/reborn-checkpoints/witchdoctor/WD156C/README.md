2. 所有这12个按钮共用修复，包含狂乱灵魂9004132及此前战刃、群蛇等条目，不按新技能逐个打补丁。被动、未学习预览、等级不够、空槽无安全施法动作；普通点击只一次、Alt自施法保留，Shift链接/Ctrl拾取及其组合不再兼带一次施法，宠物右键以原生安全宏切换自动施法。拖动/分类/专业显示保留。
3. 战斗期间停止刷新技能列表和重写受保护按钮属性，翻页/切分类延后；20次请求合并成脱战后一次刷新。已绑定的技能按钮仍走原生安全施法。战斗中首次打开尚未绑定的页面，绑定会等脱战，不把任意过期列表写入安全属性。
4. 拟态守卫：用户明确确认官方右上角同图标Buff是守卫存在时间，基础约12秒，**不是60秒技能冷却**。本包增加服务器原生显示Aura9004140，与拟态技能同名同图标，施放成功后按实际召唤计时设置时长；持续时间加成自动体现在实际计时，多守卫共用一个提示，以仍存活且属于自己的守卫最长剩余时间为准。全部死亡/消失、替换旧守卫、召回、取消学习、玩家死亡/切图/离线时移除或更新。不新增伤害/治疗/复制次数、冷却修改或战斗Proc。新Aura不进技能书、不消耗资源，AddAura不经过施法触发链。

# WD153A 三技能联动测试包（候选，尚未游戏验收）

适用基线：已安装并通过 WD152B；源码提交 2c3693e395b5d9ca3d20d6276314cb3632645629，wowshub/threemodelcardpro。不是整职业完成包；本包不要和其他同时修改公共文件的候选混覆盖。

## 本批内容及测试方法

1. 魔精高涨（Mojo High，节点6010）：额外1个拟态守卫，所有拟态持续时间+3秒。需要已学习“拟态守卫”才能观察；分别测试无两天赋、仅天选之人、仅魔精高涨、两者都有，预期1/2/2/3个。重新施放替换自己原来的拟态组；召唤部分失败保留原组。持续时间在召唤时快照，移除魔精会撤销它提供的额外拟态，已有其他拟态沿用召唤时寿命。
2. 妖火群蛇（Hexfire Mass，节点11164）：自己的恶意妖术 Hex of Malice 实际周期伤害有30%几率在敌人位置召唤独立蛇守卫，基础10秒，共享3秒内置冷却。不是Jinx诅咒，也不由恶意妖术直接命中触发。蛇守卫会继承现有守卫时长修正及巫毒之火/灵魂打击者联动，成功召唤可推进已选真灵魂。不要用单次没触发判断失败；给多个木桩上恶意妖术并观察数轮。原普通蛇守卫和瑟拉图斯群蛇应保留。
3. 巨蛇诡计（Serpent's Guile，节点29981）：需要暗影附魔及23点此前暗影TE。恶毒箭 Malefic Arrow 命中后增加4秒自然毒伤，每秒取该箭实际伤害的15%，共4跳；没有额外暴击等级。目标应出现“巨蛇之毒”图标及剩余时间。同一玩家再次命中刷新，不堆叠；不同玩家各自拥有毒伤。自然抗性/目标减伤仍按核心结算，不能把战斗中每跳强行等同未减免的15%。取消天赋或切换不含该天赋的方案会清理本人的毒伤。

保存后才生效，只有当前激活暗影方案授予本批被动；不用在技能书找新的主动技能。保留原138槽及全部旧节点映射，新增138/139/140槽、154/155/156位，协议40位十六进制。

## 安装

先退出游戏/MPQEditor；停止服务端后备份当前源码、客户端Interface、完整Data/patch-XA.mpq、服务端Data/dbc，以及角色数据库。包内backup_原文件只包含覆盖前文件，不是玩家数据库备份。

1. 把01_覆盖到源代码根目录内的文件覆盖到源码根目录，由你编译。没有附worldserver.exe/PDB，不覆盖配置。
2. 角色库依次执行03_导入SQL/characters_角色数据库/01_node_reference.sql、02_save_rows.sql。这两份是累计节点/保存规则，不再先执行旧152A的01/02。
3. 世界库执行03_导入SQL/world_世界数据库/01_WD153_world.sql。该脚本为增量，保留已安装WD152B及更早世界SQL；不是用它替换整个世界库。
4. 把04_覆盖到服务端根目录内Data/dbc覆盖到服务端；8张表均以服务端自己的当前基线合并。
5. 把02_覆盖到客户端根目录内Interface覆盖到客户端；把“导入现有PATCH-XA”目录的全部内容按原路径导入现有Data/patch-XA.mpq。不要把这个目录压成小MPQ替换完整XA；不要写patch-enUS-5.mpq或PATCH-ZA。8张客户端DBC来自客户端自己的XA，不能拿服务端DBC替代。
6. 关闭MPQEditor，启动你编译的服务端并重新进入游戏。先观察登录Lua错误、旧方案和UI，再逐项测试以上三个新天赋。

回退：停服/退出游戏后，恢复同批备份的源码/程序、Interface、完整XA和服务端DBC。若已保存含新增节点的方案，不可只覆盖旧程序；先保留角色库备份并将新增节点方案撤销，或按停服前数据库快照整体恢复。不要删玩家天赋数据来“解决”协议不匹配。

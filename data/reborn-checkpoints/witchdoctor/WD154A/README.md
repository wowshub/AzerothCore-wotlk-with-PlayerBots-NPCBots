- 仅幻象：隐身20秒、基础冷却180秒，立即获得灵魂至5层，移动速度提高50%，留下一个向前跑开的分身。灵魂沿既有真实Aura及球体显示，不能超过5层。每秒使附近100码同地图/相位内敌人对你的当前威胁降低20%（按当前剩余威胁连续衰减，不是5秒清空）。

- 分身应复制人类模型、可见装备和主副手／远程武器外观，向前跑开，不能出现静态白模或变成蛇。头盔／披风隐藏设置沿原协议；衣柜可见条目仅对本人新分身读取，不改变其他职业／NpcBots镜像。

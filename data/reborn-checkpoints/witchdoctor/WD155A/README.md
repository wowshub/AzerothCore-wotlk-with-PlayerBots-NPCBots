## 安装

1. 退出游戏与MPQEditor，停服；备份当前源码、程序、Interface、完整patch-XA.mpq、服务器Data/dbc及角色库。助手只写独立候选目录，没有修改运行目录、编译worldserver、执行生产SQL或推送。
2. 覆盖01_覆盖到源代码根目录，由你重新编译。必须同时覆盖Spell.h、SpellInfo.cpp及模块源码；魔精施法快照新增在Spell对象内，不能混用旧头文件。累计包仍包含154的SpellHandler.cpp分身外观修复。
3. 角色库仅执行本包03_导入SQL/characters_角色数据库的最终01_node_reference.sql→02_save_rows.sql；不要再执行153/154的旧版角色SQL。
4. 世界库：尚未安装153/154时依次01_WD153_world.sql→02_WD154_world.sql→03_WD155_world.sql；已装前两批只需03。更早World SQL保留；脚本发现他人占用或错误Proc配置会报错停止，先核对冲突。
5. 覆盖04的服务端8张DBC。客户端覆盖02的Interface，把“导入现有PATCH-XA”全部内容按内部路径导入现有Data/patch-XA.mpq。双端DBC不能互换；不覆盖完整XA、不写patch-enUS-5或ZA。155本身新增3张图标、Spell/SpellIcon/SkillLineAbility变更，其他表累计保留154依赖。
6. 关闭MPQEditor后启动新程序、进入游戏。先确认无Lua错误、旧方案读取正确，再保存测试三天赋。全量服务器编译和游戏效果尚待你确认。

# 给没有披风的种族加披风：从“改错了文件”到“左右对称”的教学

## 先建立直觉
披风是一块“布”，在模型里由三角形网格组成；客户端穿披风时做两件事：（1）按披风物品的“款式号”打开一块叫 1501+款式号 的网格；（2）把披风的图贴到模型里专门留的“披风贴图槽”上。蛇人模型两样都没有，所以穿披风背后什么都没有。我们要做的，是**往模型里追加**这块网格和这个槽，不改原有的任何东西。

## 这次走的路
1. **先确认读对了文件。** 我给女性蛇人做了三版披风，都不显示。原因是游戏用的是 `sethrakf.m2`，我一直在改 `Sethrak.m2`。教训：改模型前先用日志确认游戏真正加载的路径，别凭文件名猜。
2. **日志也要验证。** 第一版诊断日志什么都没写：我假设蛇人的种族号是 62，其实是 36；还用了相对路径。诊断代码本身也要小心假设。
3. **临时开关要登记并核对撤销。** 我让用户建的 `EsteriaOff.txt` 被遗留，让别的种族变白、让测试测偏。
4. **形状一步步改，每步都有数据：**
   - 每个点各找“最近的身体点”借骨骼 → 边缘借到手臂 → 褶皱和尖角。
   - 全绑胸骨骼，披风位置跟着身体轮廓走 → 腰是凹的，披风在那里折了一下。
   - 拉成斜直线 → 像纸板。
   - 下垂+褶皱 → 太宽。
   - 像男性 → 下摆歪（身体背面点稀疏，最近点落到手臂和骨盆）。
   - **整行用同一组骨骼权重**，左右对称的褶堆，离身体 3 厘米以上，法线放平 → 用户认可。

## 记住几点
- 同一行所有顶点用同一组权重：下摆才不歪、左右才对称。
- 披风的前后位置要“几乎垂直往下”，别跟着腰的凹陷走。
- 离身体至少 3 厘米，不然两个面抢同一个深度会闪。
- 追加只做加法：原有的顶点、分段、三角形、批次逐字节不变，出问题时导回备份就是原样。
- 没有布料物理：要摆动得另做披风骨骼和每个动作的动画。

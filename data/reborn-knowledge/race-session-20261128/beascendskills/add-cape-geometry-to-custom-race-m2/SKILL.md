# 给没有披风槽的种族模型追加披风（SETHCAPE）

## 证据状态（先读）
- 2026-11-14 用户实测：蛇人男性（SETHCAPE1C）披风显示，脱下后背部干净；蛇人女性（SETHCAPE1J）用户原话“就这样吧，已经很不错了”。男性形状仍是 1C 的平板，女性是 1J 的最终形状。
- **只验证了**：蛇人男、女，这一个 64 位客户端（STRHercules/Esteria 源码基线），用户当时试的披风（主要是 20283，分组值 1）。**没验证**：别的披风款式逐一对比、跑跳转身全部动作无穿插、多机器。
- **不是布料物理**：披风是一块带褶的网格，骨骼权重让它随躯干动，没有披风骨骼和摆动动画；人族披风那种摆动需要另做骨骼动画，未做。
- 来源：`000Ascendupdate/000Ascendupdate20261114/claudefix_20261114_阶段SETHCAPE1*`（最终：男 1C、女 1J）；诊断 EXE `…CAPEDIAG1B…`（日志证据）；构建脚本见 `references/sethcape.py`。
- **测试时的开关**：2026-11-13 21:17–11-14 约 02:44 客户端根目录有我让建的 `EsteriaOff.txt`（Esteria 路径关闭），蛇人女性早期不显示的测试受它污染；最终女性 1J 是在它被停用之后测的。见 `开关文件清单_会改变行为的文件和设置.md`。

## 先确认游戏真正加载哪个文件（本案最大的坑）
- 蛇人男加载 `character\rebornuir3a\sethrak\male\sethrak.m2`（Patch-YJ）；**蛇人女加载 `…\female\sethrakf.m2`（Patch-YJ）**，不是 `Sethrak.m2`（Patch-YB）。我先后给女性做了 3 版（1A/1B/1C）全改在 YB 的 `Sethrak.m2` 上，游戏根本没用，女性一直无披风。
- 办法：诊断日志。在客户端 `GeosRenderPrep` 末尾（`CharacterComponent.cpp`）记录模型文件名、披风分段（1501–1510）VIS/hid、类型 2 贴图槽；`AddCape` 入口记种族号/性别/披风显示 ID。日志写到 EXE 所在目录 `Logs/CapeDiag.log`（用绝对路径，工作目录不一定是客户端目录；第一版只记 race==62 且用相对路径，根本没出日志；蛇人种族号实际是 **36**）。`Logs/Extensions.log` 里 OnModelSequenceLoaded 也能看到路径（库尔提拉斯就是靠它发现读错文件）。

## 客户端怎么显示披风（读源码）
- `CharacterComponent.cpp`：先隐藏 1500–1599，再显示 `1501 + 披风物品的 geosetGroup[0]`（显示分组值）。客户端 DBC 里披风物品分组值范围 **0–9** → 分段 **1501–1510**；分组值 1（2463 件，最常见）→1502；例：20283→1502，32541（泰罗克的智慧，**是披风**，分组 3）→1504。
- `AddCape`：用 `Item\ObjectComponents\Cape\<贴图>.blp` 调 `ReplaceTexture(2, texture)`；`ReplaceTexture` 按**贴图类型 2** 循环替换，所以 M2 必须有一个**类型 2 贴图槽**。
- Esteria 对自定义种族：没装披风时把几何体分组 15 设为 1500（隐藏）；装了不动。
- 披风贴图坐标：左右**镜像**，中线 u=0.99，边缘 u=0.25（贴图只用 0.25–0.99 一段），v 从上 0 到下 0.99。人族/库尔提拉斯披风同。

## 追加披风网格的方法（只追加，原有字节不动）
`references/sethcape.py` 一次做完，要点：
1. M2（版本 264）头：顶点 0x3C、贴图 0x50、替换表 0x68、材质 0x70、贴图查找 0x80、UV 集查找 0x88。**整份数组复制到文件末尾再追加**，改头里的数量/偏移：追加披风顶点（48 字节：位置、4 权重、4 骨骼序号、法线、UV1、UV2）、一个类型 2 贴图槽（无名字）、贴图查找一项指向它、替换表第 2 项指向它（女性表原来只有 1 项，要扩到 3 项以上）、一个材质（**渲染标志 4 = 双面，混合 0 = 不透明**）。
2. 四个 skin（LOD0–3）：skin 头 `<4s 5×(数量,偏移) lod>`（索引、三角形、属性、分段、批次）。追加：索引（披风顶点 id）、三角形（**绝对**下标=索引数组位置，不是相对 vertexStart；起始 <65536）、属性（每个索引 4 字节骨骼窗口序号）、10 个分段（id 1501–1510，48 字节，拷贝身体大分段的骨骼窗口字段，共用同一段顶点/三角形）、10 个批次（24 字节：材质=新材质，贴图数 1，贴图查找=新项，UV 集=UV0）。
3. **每个 LOD 的骨骼窗口不同**：属性值是相对该 LOD 窗口的序号；绑定骨骼 17（胸，key 53）在各 LOD 的序号是 5/0/0/8，腰骨骼 3 在 LOD3 窗口里没有（退化为只绑胸骨骼）。
4. 基底：用**真原件**构建（第一次导入前存下的备份），不要在已追加过的文件上再追加；输出文件夹按“导入目标”命名（`01_导入Patch-YJ_女性SethrakF_5个文件`）。

## 形状与权重：失败 → 成功（别再重复）
| 版本 | 做法 | 用户反馈/结果 |
|---|---|---|
| 1A–1C 女性 | 改在 YB `Sethrak.m2` | 女性始终无披风（改错文件） |
| 1D（女） | 每个顶点复制“最近的身体背面顶点”权重；披风 x 随身体背面轮廓 | 显示了，但边缘褶皱、左下尖角（边缘顶点借到手臂/其它骨骼） |
| 1E | 100% 绑胸骨骼 | 完整，但腰部凹陷处披风往前折（x 随轮廓从 -0.21 跳到 -0.13） |
| 1F | x 拉成一条斜直线 | “像纸板”，没有下垂感 |
| 1G | 下垂+绕肩+褶皱+胸/腰骨骼渐变 | 太宽、顶部无褶皱 |
| 1H | A 像男性（贴背轮廓+复制权重，腰凹陷不折，半宽 0.22→0.30）/B 下垂褶皱 | 用户选 A，但下摆歪 |
| 1I | A 的下半（z<1.55）整行用中线同高度顶点权重 | 下摆不歪；左折右不折、折进去那边发光闪烁 |
| **1J（最终）** | 全部行中线权重（左右对称）+ 两侧对称褶堆(1.5 厘米) + 离躯干≥3 厘米 + 法线向正后方收敛 55% | 用户：“就这样吧，已经很不错了” |

经验：
- **同一行所有顶点用同一组骨骼权重**，下摆才不歪、左右才对称；不要各自找最近点（身体背面稀疏，最近点会落到手臂/骨盆/蛇尾）。
- **披风的前后位置不要跟着身体轮廓走**（腰是凹的，会折）；要“几乎垂直往下、底边略外扩”。
- **离身体至少 3 厘米**（只按躯干算，别把蛇尾 x 到 -2.1 当身体；左右取同一限制保证对称），否则面抢深度（z-fighting）闪烁；折痕处法线向正后方收敛，去掉亮斑。
- 用数据核对再改：披风网格画图、每行 x 打印、权重按列/行统计、插进身体检查。
